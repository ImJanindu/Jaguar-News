# 📰 Jaguar News Bot

A Telegram bot that scrapes the latest news from **hirunews.lk** in real time and posts updates to the Telegram channels where the bot is added.

---

## 🚀 Features
- Fetches news in real time from hirunews.lk  
- Automatically posts updates to Telegram channels  
- Simple, lightweight, and fast  

---

## 🛠 Tech Stack
- Python 
- Telegram Bot API  
- Web scraping (BeautifulSoup / Requests)  

---

✅ **Credit**: All news content is sourced from [hirunews.lk](https://www.hirunews.lk)
